# Math Curve 2: Marketplace Submission Copy

Copy each section below into the matching Autodesk Design and Make Marketplace field.

## General Usage Instructions

1. Install Math Curve 2 and start Autodesk Fusion.
2. Open or create a design and enter Sketch mode.
3. In the Sketch workspace, choose `Create > Math Curve Sketch`. The Math Curve window opens.
4. Add functions with `+ Add function...` (a new `y = f(x)`, `x(t), y(t)`, or 3D function, or a preset). Select a function to edit its expressions and variables; the graph updates as you type or drag a variable slider.
5. Check `Draw` for the functions to create. Use `InvO`, `InvX`, and `InvY` to flip a function on its baseline.
6. Under `Place in sketch`, click `Select line` and pick an existing sketch line (its start point is the origin and its direction is +x), or click `Sketch origin`. Choose the unit and the x range for `y = f(x)`. The curves are previewed in the Fusion viewport.
7. Check `Status`. If a discontinuity or a heavy calculation is found, review it and check `Draw anyway` to continue.
8. Click `Create Curves` to generate the curves in the sketch.

## Installation / Uninstallation

Installation:
1. Download the installer from Autodesk Design and Make Marketplace.
2. Run the installer. It installs Math Curve 2 in the Autodesk ApplicationPlugins folder.
3. Start or restart Autodesk Fusion. The command is available from `Sketch > Create > Math Curve Sketch`.

Uninstallation:
1. Close Autodesk Fusion.
2. Open Windows Settings > Apps > Installed apps.
3. Select Math Curve 2 and choose Uninstall.
4. Restart Autodesk Fusion if it was open during the uninstall process.

## Support Information

Math Curve 2 is compatible with Autodesk Fusion on Windows only. Simulation is not supported.

Licensing: Math Curve 2 provides a 30-day trial with full feature access. The trial and paid entitlement are verified through Autodesk Design and Make Marketplace Entitlement API. The add-in enables curve creation only when the signed-in Autodesk account has a valid Marketplace entitlement. An internet connection is required for license verification; the add-in does not cache license approvals locally.

Privacy: Math Curve 2 processes design geometry locally. For license verification only, it sends the signed-in Autodesk user ID and the Marketplace app ID directly to Autodesk's Marketplace entitlement service. No project data, credentials, analytics, or personal data are sent to the publisher or other third parties.
